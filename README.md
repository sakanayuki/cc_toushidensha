# 投資伝車

日本各地の鉄道路線と、普通／急行／特急の停車駅を忠実に再現した、旅行型の資産形成ボードゲーム。
GitHub Pages で動く静的 Web アプリです。

**公開URL**: https://sakanayuki.github.io/cc_toushidensha/

## 遊びかた

1. サイコロを振る**前に**、普通・急行・特急のどれに乗るかを選びます。
   停車駅の数で進むので、普通で4駅先の駅が、急行なら1駅で着くこともあります。
2. サイコロを振ると、**ちょうどその数だけ先の停車駅**が地図上に光ります。そこから1つ選んで移動します。
3. 到着した駅の産業を1つ選んで投資します。
4. 各ゲームでは9種類のトロフィーから5枚が抽選され、それぞれの1位が受賞。最多の人が優勝です。

乗れるのは**その駅に停車する種別だけ**です。普通しか停まらない小駅に降りると次も普通しか選べないので、
「どこまで進むか」と同じくらい「どこに降りるか」が重要になります。

## 画面

- **デザインシステムは Material 3 Expressive**。配色は Material 公式の
  material-color-utilities で生成しているので、コントラスト比と色相の調和が仕様どおりになる。
  ライト／ダークの両方に対応（端末の設定に追従）。
- **路線図は日本地図の上に重ねて描く**。投影は Web メルカトルで、駅も海岸線も同じ関数で
  変換するため、路線が実際の位置関係どおりに乗る。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ルールエンジンのテスト＋データ整合性の検証
npm run build    # 型チェック＋本番ビルド
```

配色と地図データは生成物なので、変えるときはスクリプトから作り直す。

```bash
npx vite-node scripts/build-theme.ts                      # 配色（ソースカラーはスクリプト内）
python3 scripts/build-japan-geojson.py <入力> <出力>        # 日本地図の簡略化
```

`main` への push で GitHub Actions がテストを実行し、通れば GitHub Pages へデプロイします。
テストが落ちた場合はデプロイしません。

## 構成

```
scripts/     配色と地図データの生成スクリプト
src/
  data/      路線・駅・産業のデータ（TypeScript のデータモジュール）と日本地図
  engine/    ルールエンジン（UI に依存しない純粋関数）
  ui/        React コンポーネントと Material 3 のトークン／部品
  __tests__/ ルールエンジンのテストとデータ整合性の検証
docs/
  DESIGN.md  設計仕様書（全決定事項とデータスキーマ）
```

ルールエンジンは UI から完全に独立しているため、単体でテストでき、
将来オンライン対戦を追加する際もそのまま再利用できます。

## データについて

駅の位置や路線の接続には公開データがありますが、**「この特急がどの駅に停まるか」を網羅した
機械可読なオープンデータは実質存在しません**。時刻表由来の情報であり、ダイヤ改正のたびに変わります。

そのため停車駅データは生成物であり、一定の誤りを含む前提で扱っています。
修正しやすいよう `src/data/lines.ts` に外出ししてあり、CI でデータ整合性
（孤立駅・停車駅の順序・参照切れ、駅の座標が都道府県の範囲に収まっているかなど）を
自動検証しています。

## 出典

地図データは **地球地図日本（国土地理院）** 由来の都道府県ポリゴンを、
配信できるサイズまで簡略化して同梱しています（利用条件が出典の明記のため、
アプリ内の地図にもクレジットを表示しています）。
